Agents next to your code

Agent and shell tabs share a window with a file explorer and a viewer that edits, diffs against HEAD and renders Markdown.

Every repo's changes

The Changes panel lists what changed in every git repo under the folder. Click a file to preview its diff.

Picks up where you left off

Windows, workspaces and tabs come back on launch. Updates install in place and restore the session.

Kept on the keyboard

Every panel has a shortcut. The full list is in the README.

  • New Claude tab⌘T
  • Open a folder as a workspace⌘O
  • Toggle explorer⌘B
  • Toggle Changes panel⌘⇧G
  • Diff the open file against HEAD⌘⇧D
  • Open the file in VS Code or Cursor⌘⇧O
