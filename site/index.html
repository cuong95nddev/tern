Send

Every agent in one list

Claude Code, Codex and OpenCode tabs of every open folder: Working, Needs input or Done, with each agent's latest sentence and tool.

Terminal or chat

Switch a Claude tab between its terminal and a chat view of the same conversation, and back.

Context limits and handoffs

A ring shows how full each Claude tab's context is. Past a limit you set, Claude writes a handoff and goes on in a fresh conversation.

Usage at a glance

Your Claude plan's 5-hour and weekly limits, per account, and the CPU and memory each terminal takes.

Screenshots for agentsmacOS, Windows

Capture a region, a window or the screen, mark it up, and send a few with a prompt to an agent.

Sessions that outlive the app

Terminals keep running after you quit, update or crash, and come back attached with their scrollback.

Changes, commit and log

The git changes of every repo under the folder, a diff on click, a review of them all, commit and the log.

Code navigation

File tabs go to definition, implementations and super method through language servers, with gutter icons.

Palette and search

Commands and files in one palette (⌘P), and a search in files over an index, fast on big repos.

Services for agents

Agents start dev servers through tern --mcp; the Services panel shows their ports, logs and a stop button.

A fast terminal

GPU-rendered, drawn at the display's rate, scrolled by pixels, with find, OSC 52 and kitty images.

Panels where you want them

Edit the layout: dock panels on either side, in groups, among the panes or in a window of their own. Split panes in a grid.

From your phone

tern --web serves your terminals over Tailscale. Allow a device to type, and take the session back when you are at the desk.

Themes agents can change

Themes, fonts and layout are plain files applied as you save. Ask an agent to restyle Tern and it sees the result.

macOS, Windows, Linux

Native on all three, written in Rust, with updates that install themselves and keep your session.
