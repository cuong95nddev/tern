Send

Every agent in one list

Claude Code, Codex and OpenCode terminals of every open folder, each with Working, Needs input or Done.

Agent monitor

A small window of its own that keeps every agent's state in view while you work elsewhere.

Screenshots for agentsmacOS, Windows

Capture a region, a window or the screen, mark it up, and send a few with a prompt to an agent.

Sessions that outlive the app

Terminals keep running after you quit, update or crash, and come back attached with their scrollback.

Every repo's changes

The Changes panel lists what changed in every git repo under the folder. Click a file for its diff.

Explorer and editor

Browse the folder, edit files, diff against HEAD and preview Markdown next to the agents.

Panels where you want them

Dock a panel on either side, among the panes, floating, or in a window of its own. Split panes in a grid.

From your phone

tern --web serves your terminals to a browser over Tailscale, to answer an agent away from the desk.

Settings in plain files

Themes, fonts and layout are files, applied as you save, easy for an agent to edit.
