Show the agent what you mean

Press ⌘⇧2 in any app. The screen freezes; pick a region and mark it up, collect a few, write a prompt and send them all to an agent tab, or start a new Claude Code, Codex or OpenCode tab with them.

  • Boxes, arrows, text and numbered markers to point at things
  • Mosaic to hide what the agent shouldn't see
  • A tray that holds several shots for one prompt

Background sessions

Quit Tern, keep the work running

Terminals run in a small background process, so quitting, an update or a crash doesn't stop a long agent turn or a dev server. At the next launch every tab comes back attached to the same program, with its screen and scrollback.

  • On macOS, Windows and Linux: a small background process holds the terminals (ConPTY on Windows)
  • A menu bar icon lists every background terminal, also while Tern is closed: the count, and a dot when one waits for you. Open or end any of them from it (macOS)
  • Notifications when a Claude turn finishes or needs approval, even with Tern closed (macOS)

Tabs and panes

Lots of agents, still in order

Put tabs in groups like a browser's: a name and a color each, collapse the ones you're not watching, start a new Claude or shell tab right inside one. Groups are saved with the workspace.

  • Split panes by dragging a tab to an edge, or ⌘\
  • Layouts for big screens: 2–4 columns, rows, grids up to 3×3, or Tile All Tabs
  • Tab strip that scrolls, wraps, or runs down the side as a vertical list

macOS, Windows and Linux

One native app, rendered on the GPU on every platform. Free and MIT licensed.

macOS

12+ · Universal (Apple Silicon and Intel)

  • Drag Tern from the .dmg to Applications
  • Screenshots and the menu bar icon
  • Updates install themselves, keeping your session
Download .dmg

Windows

10 (1809+) and 11 · x64

  • Installs for your user, no admin rights
  • Optional tern command and Open in Tern in Explorer's folder menu
  • Shell tabs run PowerShell 7 when installed
  • Not code-signed yet: SmartScreen asks first (More info ▸ Run anyway)
Download installer

Linux

x86_64 · X11 or Wayland · Vulkan

  • Unpack and run install.sh: tern in ~/.local/bin, a menu entry and icons
  • Mesa's Vulkan driver is fine
  • Tells you when an update is out
